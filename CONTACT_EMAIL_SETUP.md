# LUXSTAR — настройка заявок по электронной почте

## Что реализовано
Контактная форма в `index.html` посылает JSON на `POST /api/inquiry`. Серверная функция `functions/api/inquiry.js` выполняется на **Cloudflare Pages** и отправляет письмо с помощью **Resend**. API-ключ никогда не передаётся в браузер. Если отправка не удалась, посетитель видит ошибку и форма сохраняет данные.

## Требования к размещению
Нужна публикация репозитория как **Cloudflare Pages** (сборка: без build command, output directory: `.`, корень проекта). **GitHub Pages и обычный статический хостинг не исполняют `functions/`**, поэтому только загрузки файлов на GitHub недостаточно.

## Настройка
1. Подключите домен к выбранному почтовому провайдеру (Google Workspace, Zoho Mail и т. п.) для полноценного корпоративного почтового ящика.
2. Зарегистрируйте и подтвердите отправляющий домен в Resend. Добавьте рекомендуемые Resend DNS-записи (SPF/DKIM) по инструкции провайдера; не заменяйте без проверки MX-записи корпоративного почтового ящика.
3. В Cloudflare Pages → Settings → Variables and Secrets укажите:
   - `RESEND_API_KEY` — **Secret**, ключ Resend;
   - `CONTACT_TO_EMAIL` — адрес, куда поступают заявки, например `info@your-domain.example`;
   - `CONTACT_FROM_EMAIL` — подтверждённый Resend адрес отправителя, например `LUXSTAR <leads@your-domain.example>`.
4. Повторно разверните Pages, затем отправьте тестовую заявку и проверьте доставку, папку «Спам» и журнал функций.

## Защита и эксплуатация
Сервер валидирует обязательные поля и ограничивает объём запроса. Для публичного запуска настройте ограничение частоты запросов в Cloudflare WAF для `/api/inquiry`. Для дополнительной антибот-защиты рекомендуется Cloudflare Turnstile: серверный код поддерживает `TURNSTILE_SECRET_KEY`, **но не включайте этот ключ, пока на форме не добавлен виджет, передающий `turnstileToken`** — иначе все заявки будут отклонены.

## Важно
Без реального домена, настроенного Resend и переменных Cloudflare Pages нельзя подтвердить доставку заявок. GitHub PR содержит только код, не готовую почтовую учётную запись.
